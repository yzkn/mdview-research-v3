## 1. 要件

### R-01. HTML の表のセルをつなぐ・分ける

（v2.8.0 の要件定義書 §5.2）

- WYSIWYG で HTML の表のセルを**選んだ範囲**（2 つ以上のセルにまたがる）を、**1 つのセルにつなぐ**（`colspan`・`rowspan` を付け、覆われたセルの `<td>` を消す）。
  選んだ範囲は長方形に広げる（結合したセルが範囲からはみ出すなら、それを含むまで広げる）
- つないだセルの中身は、左上のセルに、ほかのセルの中身を `<br>` で区切って足す（空のセルは飛ばす。§0.2）
- キャレットのある**結合したセルを分ける**（`colspan`・`rowspan` を外し、覆っていた所に空のセルを足す。中身は左上に残る）
- 道具の帯（表のアイコン）・編集 → 表・コマンドパレットから使う。Markdown の表では使えない（その旨を知らせる）
- 取り消し 1 回で戻る

### R-02. 結合したセルのある表の行・列の足し消し

（v2.8.0 の要件定義書 §5.2。v2.8.0 では断っている）

- 行を足す: 足す所を縦に結合したセルがまたぐなら、その `rowspan` を 1 つ増やし、足す行にはそのぶんのセルを作らない
- 行を消す: 消す行を縦にまたぐセルは `rowspan` を 1 つ減らす。消す行から始まる縦に結合したセルは、次の行の同じ列へ移す（`rowspan` を 1 つ減らして）
- 列を足す・消す: 行と同じ考え方で `colspan` を増やす・減らす
- 寄せ方: キャレットの列から始まるセルに当てる（いまと同じ）
- 書き換えたあとも表として読めること。読めなくなるなら書き換えずに知らせる

### R-03. 決まった HTML を描く

（v2.8.1 の要件定義書 §5.2。いまのプレビューは `<img>` と `<table>` 以外の HTML のかたまりを描かない）

- 次のタグを、プレビュー・WYSIWYG・PDF で描く。HTML の書き出しでは、読んだ中身から書き直す（元の属性は出さない。v2.8.0 の表と同じ）

|タグ|描き方|
|---|---|
|`<details>`・`<summary>`|畳める見出しと中身（§0.2）。中身は Markdown として描く|
|`<kbd>`|キーの形（枠と地の色）|
|`<sup>`・`<sub>`|上付き・下付き（小さい字）|
|`<mark>`|蛍光ペンの地の色|
|`<br>`|段落の中の改行|
|`<ins>`・`<del>`・`<s>`|下線・取り消し線|
|`<abbr>`|字のまま（説明は出さない）|

- 段落の中のタグ（`<kbd>` など）と、ブロックのタグ（`<details>`）の両方を扱う
- 読めない形（閉じていない・知らないタグの混じったもの）は、いまどおり描かない
- WYSIWYG で `<details>` の中身・タグの中の字を直せる（タグ自体は残す）
- 設定で決まった HTML を描かないこともできる（既定は描く）

### R-04. PowerShell・TOML の複数行の色付け

（v2.8.1 の要件定義書 §5.2。v2.8.1 は 1 行の中まで）

- TOML の `"""`・`'''` の文字、PowerShell の `<# #>` の注釈と here-string（`@" "@`・`@' '@`）が**行をまたいでも**、閉じるまで文字・注釈の色を付ける
- 編集画面・プレビュー・PDF で同じ。直したブロックだけ色付けし直す（いまと同じ）

### R-05. 実機での確認で見つかった不具合

- 受入確認チェックリスト R-1・S-3・S-4・T-1〜T-3 ほかの目視で見つかった不具合（あれば）

## 2. 設定ファイルに足す項目と設定画面

`settings.toml` に足す。**読めない値は既定値**にする（いまと同じ）。名前と細かい値は設計で決める。
**どの項目も設定画面から変えられ、項目ごとに「既定」に戻せる**（v2.1.0 R-03 と同じ）。

|機能|項目|既定|設定画面の分類|
|---|---|---|---|
|決まった HTML（R-03）|`<details>`・`<kbd>` などの決まった HTML を描くか|描く|プレビュー|

R-01・R-02 は表の道具、R-04 はいまの色付けの設定（言語ごとの色を付ける）を使い、項目は足さない。

## 6. 受け入れの確かめ方

単体試験と GUI 試験（`tools/automation/spec_test.py`）の項目を足し、受入確認チェックリストに目視の節を足す。

- セルをつなぐ・分ける・結合のある表の行と列の足し消しは、**直す前と後の原文を比べる試験**で、触っていないセル・タグ・属性が変わらないこと、
  書き換えたあとも表として読めることを確かめる
- 決まった HTML は、描いた字の並びと HTML の書き出しの中身を単体試験で確かめる

締めに **release で組み、煙試験と `spec_test.py --perf`** を流す。
