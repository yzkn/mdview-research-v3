## 1. 要件

### R-01. PowerShell と TOML の色付け

（v2.0 からの制限事項「`powershell` と `toml` のコードブロックは色が付かない」。v2.8.0 でソースファイルにも色を付けるようになり、`.ps1`・`.toml` で目立つ）

- コードブロックの言語（` ```powershell `・` ```ps1 `・` ```pwsh `・` ```toml `）と、拡張子 `.ps1`・`.psm1`・`.psd1`・`.toml` のファイルに色を付ける
- 色を付けるもの: 注釈・文字・数・キーワード・変数（PowerShell の `$名前`）・コマンドレット（`動詞-名詞`）・真偽（TOML の `true`・`false`）・
  日付と時刻・表の見出し（TOML の `[名前]`）・鍵（TOML の `名前 =`）
- 色はほかの言語と同じ役割の色（テーマの明暗に合わせる）
- PDF・HTML の書き出しのコードブロックも同じ色付け（いまと同じ道を通る）

### R-02. プレビューのタブの幅

（v2.8.0 の確認の絵で見えた。編集画面はタブ幅の設定どおりなのに、プレビューではタブが 8 字ぶんに広がる）

- プレビュー・WYSIWYG・PDF のコードブロックと、テキストとして読む文書のタブを、**設定「タブ幅」と同じ字数**で並べる
  （行の頭からの桁で次のタブ止めまで。編集画面と同じ）
- WYSIWYG でコードブロックの中を直すとき、キャレットはタブの前か後ろにだけ置き、タブを広げた途中には置かない
- 原文のタブは変えない（描き方だけ）

### R-03. いまの一致の既定の色

（v2.8.0 の確認で見えた。いまの一致の既定の色（橙）が、比べる画面の違いの色（橙）と見分けにくい）

- 設定「いまの一致の色」が空（既定）のときの色を、比べる画面の違いの色（赤・緑・黄・橙）と違う色相にする
- 明るいテーマ・暗いテーマのどちらでも字が読めること
- 設定で色を指定していれば、いままでどおりその色

### R-04. 実機での確認で見つかった不具合

- 受入確認チェックリスト R-1（PPTX を PowerPoint で開く）・S-3（Linux の中継先）・S-4（同梱フォントの無い PC で PPTX を開く）ほかの
  目視で見つかった不具合（あれば）
