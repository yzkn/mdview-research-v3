# Linux 版を WSLg で確認する

対象: v2.0.0 以降
最終更新: 2026-10-05

---

## 0. なぜこれを書くか

**Linux の実機が無い。** そのため Linux 版は「組み立てと自動試験は通って
いるが、画面を誰も見ていない版」として配ることになっていた
（[リリース手順](リリース手順.md) §5）。

Windows 11 の **WSLg** を使うと、その一部を埋められる。
**全部ではない。** 何が埋まり何が埋まらないかを先に書く。

> **ここで「確認した」と書けるのは、下の表で「できる」と書いたものだけである。**
> 性能とデスクトップ統合は、WSLg で見ても実機の裏づけにならない。

---

## 1. 何が確かめられるか

### できる

|項目|受入条件|なぜ確かめられるか|
|---|---|---|
|**起動して窓が出る**|A2-06 の一部|WSLg が Wayland と X11 の両方を出す|
|**日本語の字形が正しい**|**A2-03**|**フォントを同梱している**ため、Linux 側のフォント設定に依存しない。実機とほぼ同じ結果になる|
|画面の中身（レイアウト・色・テーマ・目次・図・数式・画像・不可視文字の印）|—|描画は自前。OS の部品を使っていない|
|編集・検索置換・文字コード・PDF / HTML 出力|—|画面に依存しない部分が多い|
|**`.deb` の導入・起動・削除**|—|依存（`libc6` / `libx11-6` / `libx11-xcb1` / `libxcursor1` / `libxi6` / `libxkbcommon0` / `libxkbcommon-x11-0` / `libwayland-client0`。v2.1.1）は Ubuntu のデスクトップに既定で入っている。**WSL の既定の環境には無いものがあるので、`apt install ./…` で入れる**|
|設定ファイルの置き場（XDG）|§13.5|`$XDG_CONFIG_HOME` の経路を通る|

### できない

|項目|理由|
|---|---|
|**性能（60fps）**|**A2-02 の裏づけにならない。** WSLg には dzn（D3D12→Vulkan）の ICD が無く、Vulkan は **lavapipe（ソフトウェア描画）**になる|
|ネイティブドライバ由来の描画不具合|NVIDIA / AMD / Intel の実ドライバを通らない|
|**IME**|**A2-04 の裏づけにならない。** WSLg に IME は無い。fcitx5 + mozc を入れても、それは「WSLg 上の fcitx」であって実機のデスクトップ環境ではない|
|`.desktop` / MIME / ファイルの関連付け・通知・ウィンドウマネージャの挙動|デスクトップシェルが無い|
|AppImage の通常の起動|FUSE が要る。`--appimage-extract-and-run` で回避できるが、それは普通の使い方ではない|

### 確かめる価値があるもの（WSLg 特有ではないかもしれない）

- **ファイルを開く／保存するダイアログ**（`rfd`）。
  **2026-10-06 に見た結果は下記。**

## 2. 使う配布物

**CI が作ったものを使う。** 手元でビルドすると、配るものと別物を見ることになる。

1. Release から `mdview-<版数>-linux-x86_64.deb` を落とす
2. Windows 側の置き場（例: `%USERPROFILE%\Downloads`）に置いたまま使う。
   WSL からは `/mnt/c/Users/<利用者>/Downloads/` で見える

## 3. 手順

### 3-1. 入れる

```bash
wsl -d Ubuntu
sudo apt install ./mdview-2.0.0-linux-x86_64.deb
mdview --version      # mdview 2.0.0 と出ること
```

**`dpkg -i` ではなく `apt install ./...` を使う。** 足りない依存があれば
apt が解決し、**何が足りなかったか**が残る（実機で要るものが分かる）。

### 3-2. 窓を出す

```bash
mdview ~/screenshot.md
```

### 先に踏む壁: `NoCompositor` で落ちる

```
panicked at iced_winit: Create event loop:
  WaylandError(Connection(NoCompositor))
```

**`XDG_RUNTIME_DIR` が空の置き場を指している。** WSLg は
`/mnt/wslg/runtime-dir` に `wayland-0` を置き、これを `/run/user/<uid>`
へ結び直すのだが、**systemd のユーザーセッションが起動に失敗していると
結ばれない**（起動時に `Failed to start the systemd user session` と出る）。

確かめ方と回避:

```bash
ls /run/user/$(id -u)/          # 空なら結ばれていない
ls /mnt/wslg/runtime-dir/       # wayland-0 はこちらに在る

XDG_RUNTIME_DIR=/mnt/wslg/runtime-dir mdview ~/screenshot.md
```

**これは WSLg 側の事情であって、アプリの不具合ではない。**
実機では `/run/user/<uid>` が正しく作られる。

### それでも出ないとき

|試すこと|分かること|
|---|---|
|`echo $WAYLAND_DISPLAY $DISPLAY`|WSLg が動いているか（`wayland-0` と `:0`）|
|`WAYLAND_DISPLAY= mdview ...`|X11（Xwayland）なら出るか|
|`WGPU_BACKEND=gl mdview ...`|Vulkan ではなく OpenGL なら出るか|
|`RUST_LOG=warn mdview ...`|どこで止まっているか|

> **描画が遅くても不具合ではない。** lavapipe（ソフトウェア）で描いている
> 可能性が高い。速さはここでは測らない。

### 3-3. 見る

[受入確認チェックリスト](受入確認チェックリスト.md) の「実機」印のうち、
**§1「できる」に挙げたものだけ**を実施する。
**できないものに印を付けない。**

### 3-4. 消す

```bash
sudo apt remove mdview
```

設定ファイルが残らないことも見る（`~/.config/mdview/`）。

## 3-5. 2026-10-06 に見た結果（v2.0.0）

Release の `mdview-2.0.0-linux-x86_64.deb` を展開して動かした。

### 出たもの

|見たもの|結果|
|---|---|
|窓が出る|**出た**。起動〜初回描画 179ms|
|**日本語の字形**|**正しい。** 見出し・表・本文とも崩れなし|
|レイアウト（分割・目次・行番号）|**正しい**|
|表・箇条書き・チェックリスト|**正しい**（`☑` / `□` とも）|
|**Mermaid の図**|**出た。日本語のラベルも出る**（「在庫を数える」「不足あり」）|
|**数式**|**出た**（`$$` の囲みが `k = ⌈n/c⌉` として描かれる）|
|**画像**|**出た**|
|メニューと割り当て文字の下線|**出た**（`ファイル(F)` の `F` に下線）|

### 出なかったもの

**ファイルを開く（`Ctrl + O`）が、何も起きない。**

原因は WSL の既定の環境に **D-Bus のセッションバスも
`xdg-desktop-portal` も無い**ことである。

```
DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus   # この socket が無い
dpkg -l | grep portal                                   # 1 件も無い
```

`rfd` の Linux 側は **portal（ashpd / D-Bus）だけ**で組んでおり
（`gtk3` の機能は入れていない）、portal に繋がらないと選択は
`None` を返す。アプリはそれを**「取り消した」と区別できず**、
黙って何もしない。

> **当初「ダイアログの窓は開くが中身が描かれない」と書いた。誤りである。**
> 画面を撮った矩形に別の窓が入り込んでいたのを、ダイアログと取り違えた。
> `rfd` は GTK を含まない構成なので、**窓そのものが作られない。**
> 起動時に出る EGL / MESA の警告は wgpu が裏側を探すときのもので、
> これとは関係が無い。

### ついでに分かったこと

**速さは測っていない。** 上の 179ms は「ソフトウェア描画でも 179ms だった」
という意味でしかなく、A2-02 の裏づけにはならない。
