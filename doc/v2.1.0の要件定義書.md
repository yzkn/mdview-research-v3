# v2.1.0 要件定義書

作成日: 2026-10-08
対象: mdview v2.1.0（v2.0.1 の次の機能追加版）

---

## 0. この文書の位置づけ

v2.1.0 で入れる機能を決める。**何を・どこまで作るか**を書き、作り方は
詳細設計書 §10 の経緯欄（§10.6x 以降）に残す。

要件は 2 つの出どころがある。

|出どころ|番号|
|---|---|
|利用者が挙げたもの（7 件）|R-01〜R-07|
|v2.0.1 のあとに提案し、採用されたもの（15 件）|R-08〜R-22|

### 0.1 優先度

|区分|対象|扱い|
|---|---|---|
|**最優先**|R-08（関連付けから開く）・R-14（リストと引用の継続）|**先に入れる**（利用者の指示「速やかに」）|
|必須|R-01〜R-07・R-09〜R-13・R-15・R-18〜R-20|v2.1.0 に入れる|
|**設定で切り替える**|R-16・R-17・R-21・R-22|入れるが、**設定画面で有効・無効を切り替えられる**ようにする|

### 0.2 前回の確認事項の決定（推奨案で決めた）

v2.0.1 のあとに確認を求めた論点は、回答を待たずに推奨案で決めた。
**違っていれば、この節を直してから作り直す。**

|論点|決めたこと|理由|
|---|---|---|
|「閉じ括弧へ移動」と既存の「対応する括弧へ」の違い|**キャレットを囲んでいる括弧の、閉じ側へ移る。** 既存の「対応する括弧へ」は、キャレットの位置にある括弧の相手へ移るもので、別の操作として残す|既存のものは括弧の上に居ないと何も起きない|
|定義・型定義・宣言・実装・参照の対象|**Markdown の要素を主にする。** コードブロックの中では、**同じ言語のコードブロックを字句で探す**（言語サーバは使わない）|単一の実行ファイルという方針（§27.3）を崩さない|
|行コメント・ブロックコメント|本文では `<!-- -->`。**コードフェンスの中では、その言語の記法**に切り替える|Markdown には行コメントが無い|
|文字コード・改行コードの導線|**1 つのダイアログにまとめる**（ファイルメニューの 3 つの折りたたみを置き換える）。**自前のファイル選択には選択欄を足す。** OS のダイアログには足さない|OS のダイアログへ足せるのは Windows だけで、Linux（portal）ではほぼ足せない|
|ミニマップ|**縦のスクロールバーを、文書の縮図を描く帯にする。** 見出し・検索の一致・キャレットの位置を印で重ねる|縮図だけでは 10MB の文書で見分けがつかない。印を重ねて目印にする|
|設定の保存先|**いまの `settings.toml` に項目を足す**（§13.5）|置き場を増やすと、消すときに片方が残る|

## 1. 利用者が挙げた要件

### R-01. 縦スクロールバーのミニマップ

|項目|内容|
|---|---|
|対象|**エディタの縦スクロールバー**（プレビューは対象外）|
|描くもの|行ごとの長さを細い横棒で描いた縮図。見出しの行は濃く描く|
|重ねる印|見えている範囲（枠）・見出し・検索の一致・キャレットの行|
|操作|いまのスクロールバーと同じ（つまみを掴む・溝を押して飛ぶ）|
|設定|表示する／しない（既定: する）・幅（px）|

- **10MB（約 38 万行）でも 1 フレームに収める。** 帯の 1 画素ごとに 1 行を
  代表として選んで描く。全行は舐めない
- 折りたたんだ行（R-20）は帯にも出さない

### R-02. 常に最前面に表示

|項目|内容|
|---|---|
|起動時の状態|**常に ON ／ 常に OFF ／ 前回終了時のまま** の 3 択（設定）|
|その場で切り替える|表示メニューの「常に最前面に表示」（印つき）|
|既定|常に OFF|

### R-03. 設定画面

- ファイルメニューの「設定…」（`Ctrl + ,`）で開く。**本文を覆う画面**として描く
  （About・出力範囲と同じ扱い）
- 変えたものは**その場で効き、すぐに保存する**（他の窓へすぐに届く。R-09）
- **各項目の横に「既定」のボタン**を置く。既定と同じなら押せない
  （2026-10-08 追加の指示）
- 分類は次のとおり

|分類|主な項目|
|---|---|
|ウィンドウ|初期表示位置（R-05）・最前面（R-02）|
|エディタ|フォント・文字の大きさ・行間（R-11）・タブ幅・怪しい文字の強調・ミニマップ（R-01）|
|プレビュー|文字の大きさ（R-11）|
|外観|配色（R-13）|
|ファイル|最近使ったファイルの件数（R-12）・異常終了に備えた退避・外部変更の検知（R-21）・自動保存（R-22）・関連付けの設定を開く（R-08）|
|編集補助|リストの継続（R-14）・表の整形（R-16）・URL と画像の貼り付け（R-17）|
|キー割り当て|R-10|

#### メニューから設定画面へ移すもの

**頻繁に切り替えないもの**を移す。その場で見え方を確かめながら
切り替えるもの（表示モード・目次・空白の表示・倍率）はメニューに残す。

|移すもの|もとの場所|
|---|---|
|外観: 明るい／暗い／OS に合わせる|表示メニュー|
|タブ幅|表示メニュー|
|怪しい文字を強調|表示メニュー|
|異常終了に備えて退避する|ファイルメニュー|

### R-04. 文字コード・改行コードの導線

- ファイルメニューの 3 つの折りたたみ（開き直す・文字コードを指定して保存・
  改行コードを指定して保存）を、**「文字コード・改行コード…」1 つにまとめる**
- **ステータスバーの文字コードの表示を押しても開く**
- ダイアログで選べるもの: 文字コード・BOM の有無・改行コード
- ダイアログからできること

|ボタン|動き|
|---|---|
|この文字コードで開き直す|選んだ文字コードで読み直す（未保存の確認を通す）|
|この形式で上書き保存|選んだ形式で書く（保存先が無ければ名前を聞く）|
|この形式で名前を付けて保存|保存先を聞いてから、選んだ形式で書く|

- **自前のファイル選択**（アプリ内で開く）には選択欄を足す
  - 開くとき: 文字コード（既定は「自動判定」）
  - 保存するとき: 文字コード・BOM・改行コード（既定はいまの形式）
- OS のダイアログには足さない（§0.2）

### R-05. ウィンドウの初期表示位置

|選択肢|動き|
|---|---|
|OS に任せる（v2.2 までの既定）|いまと同じ|
|画面の中央（**v2.3.0 から既定**。v2.3.0 の要件定義書 R-01）||
|前回終了時の位置と大きさ|最大化していたかも戻す|
|座標を指定|X・Y・幅・高さを設定画面で入れる|
|画面の左半分／右半分|作業領域（タスクバーを除く）の半分に合わせる|
|最大化||

- **前回の位置が、いまの画面の外なら使わない**（モニターを外したあと
  窓が見えなくなるのを避ける）
- 左半分・右半分は**主モニターの作業領域**を使う。Windows は作業領域を
  OS に問い合わせる。他の OS はモニター全体を使う（タスクバーに重なりうる）

### R-06. 行コメント・ブロックコメントの切り替え

|操作|打鍵（既定）|本文での動き|コードフェンス内での動き|
|---|---|---|---|
|行コメントの切替|`Ctrl + /`|選んだ各行を `<!-- … -->` で包む／外す|その言語の行コメント（`//` `#` `--` など）を付ける／外す|
|ブロックコメントの切替|`Shift + Alt + A`|選んだ範囲を `<!--` と `-->` で包む／外す|その言語のブロックコメント（`/* */` など）。無い言語では行コメントで代える|

- 選んでいなければ、キャレットの行（行コメント）・キャレットの行（ブロック）を対象にする
- **すべての行がコメントなら外し、1 行でも違えば付ける**（VS Code と同じ規則）
- 1 回の取り消しで元へ戻る

### R-07. 定義・型定義・宣言・実装・参照・閉じ括弧へ移動

新しく「**移動**」メニュー（`Alt + G`）を設ける。いまの「指定行へジャンプ」
「対応する括弧へ」もここへ移す。

|操作|打鍵（既定）|Markdown 本文|コードブロックの中|
|---|---|---|---|
|定義へ移動|`F12`|参照リンク `[a][x]` → `[x]: …`／脚注 `[^1]` → `[^1]: …`／`[a](#見出し)` → その見出し|同じ言語のブロックから定義らしい行（`fn x` `def x` `class x` `x =` など）|
|型定義へ移動|`Ctrl + Shift + F12`|（定義と同じ）|型の定義らしい行（`struct` `class` `interface` `type` `enum` など）|
|宣言へ移動|`Ctrl + F12`|（定義と同じ）|宣言らしい行（`extern` `declare` 末尾が `;` のプロトタイプなど）|
|実装へ移動|`Alt + F12`|（定義と同じ）|実装らしい行（`impl x` `implements x` `extends x` など）|
|参照を探す|`Shift + F12`|見出し → そこへのリンク／定義 → それを使う箇所／脚注 → 使う箇所|同じ言語のブロックでの、語としての出現|
|閉じ括弧へ移動|`Ctrl + Shift + \`|キャレットを囲む括弧の閉じ側（§0.2）|同左|

- 見つかったものが 1 件なら飛ぶ。**2 件以上なら一覧を出し**、選んで飛ぶ
- 見つからなければ知らせを出す（黙って何もしないのが一番困る）
- コードブロックでの判定は**字句の目安**であり、言語の意味は解かない。
  そのことをヘルプと知らせの文に書く

## 2. 採用された提案

### R-08. 関連付けから開く【最優先】

v2.0.0 の B-4 で Windows の「プログラムから開く」は確認済み。残りを埋める。

|項目|内容|
|---|---|
|複数のファイルを渡されたとき|1 つ目はこの窓、2 つ目以降は**別の窓**で開く（R-09）|
|Linux の `.desktop`|`Exec=mdview %f` を **`%F`**（複数）へ改める|
|相対パス|起動したときの作業フォルダから解く|
|設定画面|「既定のアプリの設定を開く」ボタン（Windows は `ms-settings:defaultapps`）|

- **macOS の Finder から開く**（2026-10-08 追加の指示。回避策 A を採った）。
  ファイルは起動引数ではなく Apple Event で届き、いまの iced（winit 0.30）は
  受け取れない。そこで **.app の本体を Swift の小さな起動用アプリにし**、
  受け取ったファイルを mdview 本体へ起動引数で渡す
  - 本体は `.app` の中の入れ子の `.app`（`Contents/Helpers/mdview.app`）に置き、
    **別のバンドル ID** にする（同じだと、次に開いたときに受け取れない本体へ送られる）
  - 起動用は Dock に出さず（`LSUIElement`）、渡し終えたら終わる
  - 端末から引数付きで起こしたら、起動用は本体に置き換わる（`--version` などがそのまま使える）
  - **実機での確認が要る**（Swift のコンパイルは CI の macOS ランナーで確かめる）

### R-09. 複数のファイルは別の窓で開く

- **窓ごとに別のプロセス**として起こす（自分の実行ファイルを引数つきで起動する）
  - 1 つの窓に何かが起きても、他の窓の編集内容は巻き込まれない
- ファイルメニューに足すもの

|項目|打鍵|
|---|---|
|新しいウィンドウ|`Ctrl + Shift + N`|
|新しいウィンドウで開く…|`Ctrl + Alt + O`（R-18 を参照）|

- 窓へファイルを落としたとき
  - **いまの文書が無題で未編集なら**この窓で開く
  - それ以外は別の窓で開く（未保存の確認を出さずに済む）
  - 複数を落としたら、2 つ目以降は必ず別の窓
- 設定は窓をまたいで共有する（設定ファイルが 1 つのため）。**窓をまたいでも
  変更が消えないようにする**（2026-10-08 追加の指示）
  - 設定画面で変えたものは**すぐに**設定ファイルへ書く
  - 書くときは**その窓で変えた項目だけ**をディスク上のものへ重ねる
    （他の窓の変更を古い値で上書きしない）
  - 他の窓が書いたら、0.5 秒ごとの見張りで**取り込んでその場で効かせる**
  - 窓ごとに違ってよいもの（表示モード・目次の開閉と幅・分割比・倍率・
    スクロール同期）は取り込まない。次に起動したときの値としてだけ残る
  - 最近使ったファイルは、他の窓が新しく足したものを残す。「一覧を消す」で
    消したものは戻さない

### R-10. キー割り当ての変更

- 設定画面の「キー割り当て」で、**メニューにある操作**の打鍵を変えられる
- 設定ファイルには `key.<操作名> = "Ctrl+Shift+S"` の形で、**既定から変えたものだけ**書く
- 同じ打鍵が 2 つの操作に割り当たったら、設定画面で印を付けて知らせる
- 「既定に戻す」（1 件ずつ／すべて）
- 対象外: カーソル移動・文字入力・`Tab` / `Enter` / `BackSpace` など
  エディタが直に扱う打鍵（変えると文字が打てなくなる）。メニューの項目では、
  字下げ（`Tab`）・終了（`Alt + F4` は OS の打鍵）・最近使ったファイルの各項目（中身が変わる）
- 既定の打鍵が無い項目（表示モード・目次・PDF / HTML 出力・変換・日付の挿入など）にも割り当てられる
- 割り当てられるのは **`Ctrl`・`Alt`・F キーを含む打鍵**だけ（修飾キーの無い
  文字は本文への入力のため）
- 利用者が変えるのは **1 操作につき 1 打鍵**（既定で 2 つあるもの、例えば
  やり直しの `Ctrl + Y` / `Ctrl + Shift + Z` は、変えると 1 つになる）

### R-11. フォント・文字の大きさ・行間

|対象|設定できるもの|
|---|---|
|エディタ|フォント名（空なら同梱の PlemolJP）・文字の大きさ・行間（倍率）|
|プレビュー|文字の大きさ|

- **プレビューのフォントは変えられない。** PDF 出力と同じ測り方を保つため（§17.3）
- 表示倍率（`Ctrl + +`）は、これらに掛け合わせて効く

### R-12. 最近使ったファイル

- 覚える件数を設定画面で変えられる（1〜30、既定 10）
- 「最近使ったファイル」の折りたたみの末尾に「**一覧を消す**」

### R-13. 配色

- 明るい・暗い・OS に合わせる に加え、**iced が持つ配色**
  （Dracula・Nord・Solarized・Gruvbox・Catppuccin・Tokyo Night など）から選べる
- 本文・選択・検索の色は、いまと同じく**配色の文字色から作る**

### R-14. リストと引用の継続【最優先】

|キャレットの行|`Enter` を押すと|
|---|---|
|`- 項目`／`* 項目`／`+ 項目`|次の行に同じ記号と字下げを入れる|
|`1. 項目`|次の番号（`2. `）を入れる。`1)` の形も同じ|
|`- [ ] 項目`／`- [x] 項目`|次の行に `- [ ] ` を入れる（チェックは外す）|
|`> 引用`|次の行に `> ` を入れる（入れ子の `> > ` も保つ）|
|中身の無い項目（`- ` だけ）|**記号を消して**リストを抜ける|

- コードフェンスの中では働かない
- IME の確定の `Enter` では働かない（いまと同じく、変換中はアプリが扱わない）
- 設定で切れる（既定: 有効）

### R-15. 強調・リンク・コードの挿入と切り替え

|操作|打鍵（既定）|選んでいるとき|選んでいないとき|
|---|---|---|---|
|太字|`Ctrl + B`|`**…**` で包む／外す|`****` を入れて間へキャレット|
|斜体|`Ctrl + I`|`*…*`|同様|
|インラインコード|`Ctrl + E`|`` `…` ``|同様|
|リンク|`Ctrl + K`|`[…](url)` にして `url` を選ぶ|`[](url)`|

- 編集メニューの「書式」の折りたたみに並べる

### R-16. 表の整形【設定で切り替え】

- 編集メニュー「表を整形」（`Shift + Alt + F`）: キャレットのある表の列幅を揃える
  - 全角の字は 2 桁として数える
  - 区切り行の `:` による寄せ（左・中央・右）を保つ
- 「表に行を足す」「表に列を足す」
- 設定で無効にすると、メニューから消え、打鍵も効かない（既定: 有効）

### R-17. URL と画像の貼り付け【設定で切り替え】

|貼り付けるもの|動き|設定（既定）|
|---|---|---|
|URL だけの文字列（範囲を選んでいる）|選んだ文字を `[選んだ文字](URL)` にする|有効|
|画像（クリップボード）|文書と同じフォルダの `images/` に PNG で保存し、画像を入れる|有効|
|画像のファイルを窓へ落とす|`images/` へ写して、画像を入れる（文書のフォルダの中にあるものは写さない）|有効（上と同じ設定）|

- **入れる形は GitHub と同じ `<img>` タグ**（2026-10-08 追加の指示）。
  `<img width="幅" height="高さ" alt="image" src="images/….png">`。
  設定で `![image](…)` にも切り替えられる
- 代替の文字（`alt`）は、貼り付けなら選んでいた文字（無ければ GitHub と同じ `image`）、
  落としたファイルならファイル名（拡張子を除く）
- 画像は**それだけの行**として入れる（文の途中では画像として描けないため）
- `<img>` タグ 1 つだけの段落は、プレビュー・PDF・HTML 出力で**画像として描く**。
  `width` があればその幅まで（画面の幅は超えない）。`src`・`width`・`alt` 以外の
  属性は読まない
- 画像は**保存済みの文書でだけ**働く（置き場が決まらないため）。
  無題のときは知らせを出す
- 保存先のフォルダ名は設定で変えられる（既定 `images`）。同じ名前があれば番号を足す
- 落としたのが画像でなければ、いままでどおり文書として開く（R-09）

### R-18. 見出し単位の移動

|操作|打鍵（既定）|
|---|---|
|前の見出しへ|`Ctrl + ↑`|
|次の見出しへ|`Ctrl + ↓`|
|見出しへ移動…（絞り込み）|`Ctrl + Shift + O`|

- 「見出しへ移動…」は、打った文字で見出しを絞り込む一覧を出し、選んで飛ぶ
- `Ctrl + Shift + O` は R-09 の「新しいウィンドウで開く」と重なるため、
  **R-09 側を `Ctrl + Alt + O` にする**（下の §3 で一覧にする）
- 目次（サイドバー）にも絞り込みの欄を足す

### R-19. リンクを開く・リンク切れの検査

|操作|動き|
|---|---|
|エディタで `Ctrl` + クリック|`#見出し` → その見出しへ／相対パスの `.md` → 別の窓で開く／その他のファイル・`http(s)` → OS の既定のアプリ|
|プレビューでリンクをクリック|同上|
|移動メニュー「リンクを開く」|キャレットの位置のリンクを同じ規則で開く（`Ctrl + Enter`）|
|移動メニュー「リンク切れを検査」|相対パスのファイルが無いもの・`#見出し` が無いもの・参照の定義が無いものを一覧に出す|

- `http(s)` のリンクは**検査しない**（ネットワークへ出ない）

### R-20. 見出し単位の折りたたみ

- **エディタで**、見出しから次の同じ深さ（以上）の見出しの手前までを畳む
- 行番号の欄に ▸ ／ ▾ を出し、押すと開閉する
- 移動メニュー: 「この見出しを畳む」「この見出しを開く」「すべて畳む」「すべて開く」
- 畳んだ中へキャレットが入る操作（検索・行へジャンプなど）をしたら、
  **その部分を自動で開く**
- 畳んだ見出しの中身は、ミニマップ（R-01）とスクロールの量にも数えない
- **プレビューは畳まない**（v2.1.0 では対象外）
- 畳んだ状態は保存しない（開き直すとすべて開いた状態）

### R-21. 外部での変更の検知【設定で切り替え】

- 開いているファイルが他のアプリで書き換えられたら、知らせの帯を出す
  - 「再読み込み」「無視」
- **未編集なら自動で読み直す**こともできる（設定。既定: 確認する）
- 確かめる間隔は 2 秒（ファイルの更新時刻と大きさを見る）
- 自分で保存した直後は知らせない
- 設定（既定: 有効）

### R-22. 自動保存【設定で切り替え】

- **保存先のある文書**を、編集が止まってから N 秒後に上書き保存する
  （N は設定。既定 30 秒）
- 無題の文書は対象外（保存先を聞くダイアログを勝手に出さない）
- 異常終了に備えた退避（§18.3）とは別のもの。両方を同時に使える
- 設定（既定: **無効**。勝手に書き換わるのを嫌う人がいるため）
