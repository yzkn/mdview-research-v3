## 1. 要件

### R-01. WYSIWYG 編集

（v2.3.0 の要件定義書 §5.1 で聞き取り、v2.4.0 の R-08 から移したもの）

- 編集・分割・プレビューに加えて **4 つ目の表示モード**
- **文字・表・リスト・見出しの組み替え・図や数式まで**、描いた結果の上で直接書き換える
- 保存するのは Markdown のまま。書き戻すときは、元の書き方（`*` と `-`、`**` と `__` など）を**できるだけ保つ**。
  触った所だけ、決まった書き方（設定の既定）で書く
- **10 MB の文書で動く必要はない**（大きい文書では、このモードに入れない・知らせる。上限の既定は 1 MB。§0.2）
- 元に戻す・やり直しは、ほかの表示モードと同じ履歴を使う
- **設定で選ぶ**: 「WYSIWYG を使う」（既定は使う。切ると表示メニューと切り替えから外す）・新しく書くときの記法
  （リストの印 `-`／`*`、強調 `*`／`_`、太字 `**`／`__`、見出し `#`）・このモードに入れる文書の大きさの上限。
  設定画面の「エディタ」に欄

段ごとの中身（§0.2 の段取り）:

|段|中身|
|---|---|
|R-01 a|4 つ目の表示モードと切り替え。描いた文字と原文の対応（キャレット・選択の置き場所）。段落と見出しの上で打つ・消す・改行で分ける／つなぐ・選ぶ・写す・貼る。太字・斜体・コード・リンクの道具（打鍵と道具の帯）。設定（使う・記法・上限）|
|R-01 b|リスト（項目を足す・字下げ／戻す・番号の振り直し・チェックの入り切り）・引用・コードブロック（言語の指定と中身）・見出しの段の上げ下げと、節ごとの入れ替え|
|R-01 c|表（セルを直す・行と列を足す／消す・寄せ方）・図と数式（原文の小窓で直し、すぐ描き直す）|

### R-02. ステータスバーにファイルの大きさを出す（2026-10-21 に足した）

- いまの本文の大きさを、**単位つき**（B・KB・MB）で出す
- 保存してあるファイルの大きさが、いまの本文の大きさと違えば並べて出す（例: `12.4 KB（保存 12.1 KB）`）。
  無題の文書・URL から開いた文書では、保存の大きさは出さない
- ステータスバーと窓の題名の書式（v2.2.0）の欄 `{size}` で出し入れできる（いまの `{size}` を単位つきにする）

### R-03. Markdown のフォーマッター（2026-10-21 に足した）

- **整えること**: Markdown の検査（v2.3.0 R-11）で直せる指摘をまとめて直し、加えて次を**設定で入れ切りできる**ようにする
  - 表の桁をそろえる
  - リストの印をそろえる（**印に使う字を設定で選ぶ**: `-`・`*`・`+`）
  - 強調と太字の記法をそろえる（設定の記法。R-01 の「新しく書くときの記法」と同じもの）
  - 見出し・区切り・コードブロックの前後の空行、行末の空白、ファイルの終わりの改行（検査の直しで扱う）
- **コードブロックの中は触らない**
- **当てるとき**を、検査の直し・フォーマッターのそれぞれについて、次から**いくつでも選べる**設定にする:
  「メニューから選んだとき」「ショートカットキーを押したとき」「保存するとき」「閉じるとき」
  - 閉じるときに当てて本文が変わったら、保存してから閉じる（保存先のある文書だけ。読み取り専用・無題・URL から開いた文書は当てない）
  - 当てた変更は 1 つの編集として履歴に入り、取り消しで戻せる
- 設定画面に欄を置く（分類は設計で決める）

### R-04. イースターエッグ（2026-10-21 に足した）

- About ダイアログの決まった所を操作すると、次のものを出す（どこをどう操作するかは設計で決め、画面には書かない）
  - **ひとこと**（作った人のひとことや、隠しの言葉）
  - **絵**（アプリのアイコンを使った、動く小さな絵）
  - **ミニゲーム**（矢印で遊ぶ小さなゲーム）
  - **作った記録**（版ごとの歩みが、エンドロールのように流れる）
- ネットにはつながない。Esc で閉じる

## 2. 設定ファイルに足す項目と設定画面

`settings.toml` に足す。**読めない値は既定値**にする（いまと同じ）。名前と細かい値は設計で決める。
**どの項目も設定画面から変えられ、項目ごとに「既定」に戻せる**（v2.1.0 R-03 と同じ）。

|機能|項目|既定|設定画面の分類|
|---|---|---|---|
|WYSIWYG（R-01）|使う・新しく書くときの記法・大きさの上限|使う・`-`・`*`・`**`・`#`・1 MB|エディタ|
|フォーマッター（R-03）|表の桁・リストの印（と字）・強調と太字の記法をそろえるか、検査の直しとフォーマッターを当てるとき（メニュー・ショートカット・保存・閉じる）|設計で決める|設計で決める|

## 3. 打鍵の割り当て（既定の案）

キー割り当ての変更（v2.1.0 R-10）の対象にする。いまの割り当てとぶつからないかは設計で確かめる。

|操作|打鍵|
|---|---|
|WYSIWYG に切り替える（R-01）|（無し。§0.2）|
|Markdown を整える（R-03）|Ctrl+Alt+F（Shift+Alt+F は表を整えるで使っている）|
|太字・斜体・コード・リンク（R-01 a）|いまの編集画面と同じ打鍵（Ctrl+B など）を、WYSIWYG でも同じ意味で使う|
|リストの項目の字下げ・戻す（R-01 b）|WYSIWYG では Tab・Shift+Tab（編集画面の Tab はいままでどおり。メニューからは両方で使える）|
|チェックの入り切り（R-01 b）|Ctrl+Alt+Enter（Ctrl+Enter はリンクを開くで使っている）|
|見出しの段を上げる・下げる（R-01 b）|Shift+Alt+←・Shift+Alt+→|
|節を上へ・下へ（R-01 b）|Shift+Alt+↑・Shift+Alt+↓|
|リストの番号を振り直す（R-01 b）|（無し。字下げのたびに振り直す）|
