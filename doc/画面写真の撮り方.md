# 画面写真の撮り方（C-3）

README に載せる画面写真を撮り直す手順。**撮る人が迷わないように、
窓の大きさから設定まで決め打ちにする。**

> **写真は見た目の記録であり、版が変わるたびに古くなる。**
> 見た目を変えたときは、ここを見て撮り直す。

---

## 1. 何を撮るか

|ファイル|中身|
|---|---|
|`doc/images/screenshot-split-light.png`|**分割表示・明るいテーマ**。目次つき。左に原文、右に仕上がり|
|`doc/images/screenshot-preview-dark.png`|**プレビューのみ・暗いテーマ**。図と数式が出ているところ|

どちらも [`samples/screenshot.md`](../samples/screenshot.md) を開いて撮る。
**この文書は写真のために作ってある**（表・図・数式・コード・画像・
チェックリストが 1 画面に収まる）。

## 2. 撮る前に揃えること

**前回の設定が残っていると、写真ごとに見た目が変わる。**
撮る前に設定ファイルを退かす。

```
move "%APPDATA%\mdview\settings.toml" "%TEMP%\settings.toml.bak"
```

撮り終えたら戻す。

|項目|値|
|---|---|
|窓の大きさ|**起動したまま**（1,200 × 800）。掴んで動かさない|
|表示倍率|**等倍**（`Ctrl + 0`）|
|タブ幅|4 桁（既定）|
|空白・タブ・改行の印|**出さない**（既定）|
|怪しい文字の強調|出す（既定）|
|検索欄|**閉じる**|

## 3. 手順

```
target\release\mdview.exe samples\screenshot.md
```

### 3.1 分割・明るい

1. 表示メニュー →「分割」
2. 表示メニュー →「外観: 明るい」
3. 表示メニュー →「目次」を出す
4. **右側を先頭まで巻き上げる**（見出しが切れていると締まらない）
5. 窓全体を撮る（`Alt + PrintScreen`）

### 3.2 プレビューのみ・暗い

1. 表示メニュー →「プレビュー」
2. 表示メニュー →「外観: 暗い」
3. **図と数式の両方が入る位置まで送る**
4. 窓全体を撮る

### 3.1 試験の口で撮る（v2.1.0）

同じ大きさ・同じ状態で撮り直したいときは、試験の口（`--automation`）の `screenshot` が使える。
OS の画面取得を使わず、**窓の中身だけを PNG で書く**（他の窓やカーソルが写らない）。

```python
from mdview_driver import Mdview          # tools/automation/
with Mdview("target/release/mdview.exe", "samples/xxx.md") as app:
    app.set_setting("theme", "light")
    app.screenshot("shot.png")
```

決まりは [GUI 自動テストの方針](GUI自動テストの方針.md)。README に載せる写真は、
窓の枠も含めたいので §3 の手順で撮る。

## 4. 保存するとき

- **PNG で保存する。** JPEG は文字の縁がにじむ
- 原寸のまま置く（縮めない）。README 側で幅を指定する
- `doc/images/` の同じ名前へ上書きする

## 5. README へ戻す

v1 の写真を外したとき、README の記述ごと消してある（`doc/正式リリースへのタスク.md`
の C-2）。撮り直したら「できること」の下へ戻す。

```markdown
## 画面

![分割表示（明るいテーマ）](doc/images/screenshot-split-light.png)

![プレビュー（暗いテーマ）](doc/images/screenshot-preview-dark.png)
```

## 6. 撮り終えたら

- `doc/正式リリースへのタスク.md` の C-3 を「完了」にする
- 設定ファイルを戻す（手順 2）
