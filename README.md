# mdview

Windows / macOS / Linux で動く、**単一実行ファイル**の Markdown ビューア／エディタ。
完全オフラインで動作し、社内文書の閲覧・編集を想定している。

> 最新は **v2.9.0**（[変更履歴](CHANGELOG.md)）。
>
> **v2.0.0 で中身を作り直した。** v1 は Tauri（WebView）製で 300KB が上限だったが、
> v2 は Rust と iced による自前描画で、**10MB の文書を扱える**。
> 設計の経緯は [技術選定書](design/Markdown%20Viewer技術選定書.md) にある。

## 忙しい人向け（TL;DR）

**Markdown（マークダウン）** は、`#` や `-` といった記号を少し使うだけで、
見出しや箇条書きを表せる文章の書き方です。このアプリは、その Markdown ファイル
（`.md`）を**きれいに表示して、その場で書き直せる**デスクトップアプリです。
インターネットにつながっていなくても全機能が使えます。

### できること

- 書きながら、**仕上がりを隣に同時表示**（編集だけ / 表示だけ / 左右に並べる、の 3 通り）
- 表・チェックリスト・**図（Mermaid）**・**数式**・画像の表示
- 左側の**目次**から見出しへジャンプ
- **PDF として保存**（A4 縦。先頭に目次、下端にページ番号、見出しからしおり）
- **HTML として保存**（画像ごと 1 ファイルにまとまるので、そのまま人に渡せます）
- Shift_JIS や EUC-JP の文書も開ける。**文字コードと改行コードを選んで保存**できます
- 明るい / 暗いテーマの切替（**日の出・日の入りで自動に**も。v2.3.0）、**自分の配色**、文字の拡大・縮小
- **2 つの文書を左右に並べて比べる**。どちらの側もその場で直せ、パッチも作れる・当てられる（v2.3.0）。比べる画面でも検索・置換できる（v2.8.0）。
  **フォルダーの比較**（まとめて写す。v2.7.0）・描いた結果で比べる**プレビューでの比較**・**3 つのファイルのマージ**（v2.6.0）
- 書く手助け: **スニペット**・**目次を入れる**・**見出しに番号を振る**・**Markdown の検査**（v2.3.0）
- **集中モード**（`F11`。全画面で本文だけ。v2.3.0）
- **Marp のスライド**: スライドに分けて見せる・`F5` で発表・PDF / HTML / PPTX に書き出す（v2.4.0。PPTX は PowerPoint で文字を直せる。v2.7.0。使った字だけの字体を埋め込む。v2.8.0）
- **URL を開く**（`Ctrl + Shift + L`。読み取り専用。GitHub の画面の URL も中身を開く。v2.4.0）
- **コマンドパレット**（`Ctrl + Shift + P`。メニューの操作を名前で探して実行。v2.4.0）
- **背景画像**・**Mica 風の窓の地**（Windows）・図の拡大と PNG・コードブロックのコピー（v2.4.0）
- **MCP サーバー**。MCP クライアント（AI のアプリなど）から文書を読み書きできる（操作ごとに許可・確認・拒否。v2.4.0）
- **WYSIWYG 編集**（表示 → WYSIWYG）。記法を見せずに描いた文字の上で打ち、リスト・引用・コード・見出しを組み替える。
  表はセルの上で直し、行・列を足す／消す・寄せる。図・数式は描いた図のすぐ下の小窓で直す。
  裏では原文を書き換え、触っていない所の書き方は変えない（v2.5.0。表・図・数式は v2.5.1）
- **Markdown のフォーマッター**（`Ctrl + Alt + F`）。検査の直し・表の桁・リストの印・強調の記法をそろえる。
  保存・閉じるときにも当てられる（v2.5.0）
- **frontmatter の欄**。プレビューと WYSIWYG の頭に名前と値を並べ、その場で直せる（畳める。v2.6.0。TOML も v2.7.0）
- **ソースファイルの色付け**（`.rs`・`.py`・`.json` など。編集画面とプレビュー。v2.8.0）
- **HTML の表**（`<table>`）を表として描き、WYSIWYG でセルの上で直す（結合も描く。v2.8.0）。セルをつなぐ・分ける（v2.9.0）
- About に**使っているソフトウェア**の一覧とライセンスの全文（v2.6.0）

### 使い始めるまで（Windows）

1. **入手する** — **公開リポジトリの Releases** から、最新版の
   `mdview-<版数>-windows-x86_64-setup.exe` を落とします
   - 配布物は 2026-10-06 から公開リポジトリで組んでいます（[リリース手順](doc/リリース手順.md) §1）。
     このリポジトリの Releases は v2.0.0 で止まっています
2. **入れる** — 落としたファイルを実行します。**管理者権限は不要**で、
   自分のユーザー領域（`%LOCALAPPDATA%\Programs\mdview`）に入ります
3. **開く** — `.md` を右クリック →「プログラムから開く」→ mdview を選びます
   （アプリを起動してから `Ctrl + O` でも構いません）

> **署名を付けていないため、初回に警告が出ます。**
> 「WindowsによってPCが保護されました」が出たら **詳細情報 → 実行** を押してください。

よく使うキー: `Ctrl + S` 保存 ／ `Ctrl + F` 検索・置換 ／ `Ctrl + ,` 設定 ／
`Alt + F` ファイルメニュー

### 怪しい文字の強調

Web や Office から貼り付けると、**見えないのに悪さをする文字**が紛れ込むことがある
（ゼロ幅スペース、BOM、ノーブレークスペース、書字方向の制御文字など）。
これらに赤い枠を出す。**既定で有効**——気づく前に保存させないためである。

## 入れ方

公開リポジトリの Releases から落とす（2026-10-06 から。このリポジトリの Releases は v2.0.0 まで）。
**どれも単体で動く**（ランタイムの導入は不要）。フォントを同梱しているので、
環境によって字形が変わることもない。

|OS|入れて使う|そのまま動かす|
|---|---|---|
|Windows 10/11 (x64)|`mdview-<版数>-windows-x86_64-setup.exe`|`mdview-<版数>-windows-x86_64.exe`|
|macOS 11+ (Apple Silicon)|`mdview-<版数>-macos-aarch64.dmg`|`mdview-<版数>-macos-aarch64`|
|Linux (x64)|`mdview-<版数>-linux-x86_64.deb`|`mdview-<版数>-linux-x86_64.AppImage`|

Linux 版は **glibc 2.39 以上**が要る（Ubuntu 24.04・Debian 13 以降。Ubuntu 22.04・Debian 12 では起動しない）。

### 署名していない

**配布物に署名を付けていない**（基本設計書 §27.4）。初回起動時の警告の外し方は
Release の説明文にある。署名の代わりに **SHA-256 の照合値**（`SHA256SUMS.txt`）を添えている。

### 関連付け

Windows のインストーラで**選択制**（既定では付けない）。有効にすると
「プログラムから開く」に出る。**既定のアプリにするかは利用者が決める**
（設定 > アプリ > 既定のアプリ）。

**右クリックのメニューの「mdview で開く」**（v2.2.0）。`.md` / `.markdown` に付く。
インストーラの選択肢で既定は付ける。既定のアプリは変えないので、他の道具の邪魔をしない。
Windows 11 では「その他のオプションを確認」（`Shift + F10`）の中に出る。

> インストーラは `.md` の既定の関連付けを**書き換えない**。Windows 8 以降は
> 利用者が選んだ関連付けが優先されるため書いても効かず、消すときに
> 元の設定まで壊してしまう（詳細設計書 §10.46 付近）。

## 使い方

- **ファイルを開く**: ファイルメニュー、`Ctrl + O`、ウィンドウへのドラッグ＆ドロップ、
  エクスプローラーからのダブルクリック
- **PDF にする**: ファイル > PDF に出力。A4 縦で、先頭に目次、下端にページ番号。
  `<!-- pagebreak -->` の位置で改ページする。出力範囲を選べ、途中で取り消せる
- **HTML にする**: ファイル > HTML に出力。CSS と画像を埋め込んだ 1 ファイル
- **表示を切り替える**: 表示メニュー、または `Ctrl + 1` / `2` / `3`
- **幅を変える**: 目次・エディタ・プレビューの境界をドラッグする
- **読むだけにする**: 表示 > 読み取り専用。打つ・貼る・上書き保存を断る

### 起動オプション（v2.1.3）

```
mdview [オプション] [ファイル…]
```

|オプション|効き目|
|---|---|
|`-g`, `--goto <行>`|その行（1 始まり）を開く。行が足りなければ最終行|
|`-r`, `--readonly`|読み取り専用で開く（本文も元のファイルも書き換えない）|
|`-t`, `--always-on-top`|常に最前面で開く（設定より優先する。設定は変えない）|
|`--url <URL>`|URL の Markdown を読み取り専用で開く（v2.4.0）|
|`--mcp`|MCP サーバーとして動く（窓は出さない。MCP クライアントから標準入出力で呼ぶ。v2.4.0）|
|`-v`, `--version`|版数を出す|
|`-h`, `--help`|使い方を出す|

2 つ以上のファイルを渡すと 2 つ目からは別の窓で開き、`-r` と `-t` はそちらにも効く。

> **Windows の端末からは `mdview`（拡張子無し）と打つ。** インストーラが入れる
> 端末用の入口 `mdview.com` が起き、端末は答えが出るまで待つ。`mdview.exe` は窓の
> アプリなので、拡張子まで打つと版数がプロンプトの後ろに出ることがある。

## 制限事項

- **性能目標は 10MB**。超えても開くが、警告が出て動作が重くなる
- **右端での折り返しは 512 KB 以下のファイルだけ**（v2.2.0）。大きいファイルでは縦の位置の計算が重いため、
  設定を入れても折り返さない。折り返しは文字単位（英単語の途中でも切る）で、桁は等幅として数える
- **Markdown 以外のファイルはテキストとして扱う**（v2.2.0）。言語ごとの色は付く（v2.8.0。空行で区切った 1 ブロックが 64 KB を超えると色無し。
  上限と対象の拡張子は設定で変えられる）。PowerShell と TOML は複数行の文字・注釈も閉じるまで色を付ける（v2.8.1・v2.9.0）。
  拡張子が `.md` / `.markdown` でなければ、見出し・リストなどを解釈せず、リストの続きや表の整形も効かない
- **比べる画面の検索は、いま入力のある面だけ**（v2.8.0）。10 MB 同士の比較は時間がかかる（裏で比べ、画面は止めない）。
  プレビューでの比較は読むだけ。4 つ以上のファイルのマージは無い（v2.6.0）
- **Markdown の検査は 512 KB を超える文書では見えているあたりだけ**（v2.3.0）。編集画面の記法の色は目安で、
  CommonMark を正確にはなぞらない
- **集中モードは OS の通知を止めない**（v2.3.0）。Windows の「応答不可」・macOS の「集中モード」はアプリから入れられない
- **Marp のスライドは Marp と同じ見た目にはならない**（v2.4.0）。テーマは近いものを自前で描く。
  PPTX は文字を直せるが、折り返しは PowerPoint に任せるので画面と少しずれる。埋め込む字体は使った字だけなので、PowerPoint で
  新しく打った字は別の字体で出ることがある（v2.8.0）。アニメーションと画面の切り替えは無い（v2.7.0）
- **Mica 風の窓の地は見た目だけ**（v2.4.0）。後ろの窓は透けず、Acrylic は無い。Windows だけで、ほかの OS は不透明のまま。
  背景画像は PDF・HTML に入らない
- **URL を開くのは読み取り専用**（v2.4.0）。`http://`・`https://` だけ、20 MB まで。URL の画像は設定「画像も URL から取る」
  を入れたときだけ取る（既定は切る。切っている間はネットへ取りに行かない）。中継（プロキシ）は環境変数 `HTTPS_PROXY` などに従い、
  無ければ OS に聞く（Windows・macOS は PAC・自動検出も OS と同じ。v2.6.0・v2.7.0）。Linux は GNOME と KDE の設定を読み、
  PAC は組み込んだ処理系で評価する（v2.8.0。自動検出（WPAD）は直接つなぐ）。macOS と Linux の中継は実機で見ていない
- **MCP は手元からだけ**（v2.4.0）。HTTP は `127.0.0.1` だけで待ち、ほかの PC からはつなげない。MCP 自身の設定は MCP からは変えられない。
  窓を出さずに出力する PDF は、窓から出力したものと行の折り返しが少し違うことがある
- **WYSIWYG でセルをつなぐ・分けるのは HTML の表だけ**（Markdown の表には記法が無い。v2.9.0）。
  HTML は `<table>`・`<img>` と決まったタグ（`<details>`・`<kbd>`・`<sup>`・`<sub>`・`<mark>`・`<br>`・`<ins>`・`<del>`・`<s>`・`<abbr>`）だけを描く（v2.9.0）。図は絵の上では直さず、原文の小窓で直す（v2.5.1）。
  1 MB（設定で変えられる）を超える文書と、テキストとして読む文書では入れない。Marp の文書は普通の文書として直す
- **frontmatter の欄で直すのは表の外の値と並びだけ**（v2.6.0・v2.7.0）。YAML の入れ子・TOML の表は欄では直さず、原文の小窓で直す
- 1 つのウィンドウで扱えるファイルは 1 つ（別のファイルは新しいウィンドウで開く）。
  窓ごとに別のプロセスで動く
- **macOS 版は実機で見ていない**。組み立てと自動試験は通っているが、画面の見た目は
  誰も確かめていない。**Linux 版は WSLg で画面だけ見ている**（性能・IME・デスクトップ統合は未確認。
  [リリース手順](doc/リリース手順.md) §5）
- 単一実行ファイルや `mdview.exe` と拡張子まで打ったときは、`-v` の版数がプロンプトの後ろに出ることがある（インストーラで入れた `mdview` なら待たれる）
- その他、版ごとの「分かっている制限」は [変更履歴](CHANGELOG.md) にある
- 署名・公証をしていないため、初回起動時に OS の警告が出る

## 開発

### 必要なもの

|もの|版|備考|
|---|---|---|
|Rust|`rust-toolchain.toml` が指定|**手元と CI を同じ版にそろえる**（基本設計書 §27.6）|
|C++ ビルドツール|MSVC（Windows）|Visual Studio の「C++ によるデスクトップ開発」|
|Python 3|—|同梱フォントとアイコンの取得に使う|

**Node.js は要らない。** v2 はフロントエンドを持たない。

### 用意する

```powershell
# 同梱フォントはリポジトリに無い（21.56MB あるため）
python tools/fetch-fonts.py

# アイコン（ico / png / iconset）を作る
cargo run --release --example make-icons
```

### 作る・試す

```powershell
cargo build --release
cargo clippy --all-targets -- -D warnings
cargo test
```

> **この端末では MSVC の検出に手当てが要る。** `poc\v2-ui\build-msvc.bat` を
> 経由すると開発者環境を読み込んでから `cargo` を呼ぶ。

> **試験は設定の置き場を空のフォルダーへ向けて流す。** 試験は利用者の設定（`settings.toml`）を
> 読むので、手元の設定が `view_mode = "preview"` だと 3 件落ちる（CI は設定が無いので落ちない）。
> `--release` では組めない（iced の試験用の描画役が debug にしか無い。詳細設計書 §10.64）。
>
> ```powershell
> $env:MDVIEW_CONFIG_DIR = (New-Item -ItemType Directory "$env:TEMP\mdview-test-config" -Force).FullName
> cargo test --all
> ```

### 配布物を組む

```powershell
powershell -ExecutionPolicy Bypass -File packaging\windows\build-installer.ps1
```

Linux / macOS は [`packaging/`](packaging/) のスクリプトを参照。
**通常は GitHub Actions が組む**（[リリース手順](doc/リリース手順.md)）。

### 構成

```text
src/
  app/        画面の状態とメッセージ（iced の Application）
  document/   本文（ropey）・ブロック索引・編集履歴
  layout/     折り返し・高さの計算（**窓を持たない**ので窓無しで試験できる）
  render/     自前ウィジェット（エディタ・プレビュー・区切り）
  parse/      行走査・インライン解析・着色
  embed/      図・数式・画像
  export/     PDF / HTML 出力
  paginate/   PDF のページ分割
  edit/       編集の道具（変換・括弧・日付・怪しい文字）
  search/     検索と置換
  io/         読み書き・文字コード・設定
assets/       同梱フォント（取得する）・アイコンの原本
packaging/    配布物を組むスクリプト
```
